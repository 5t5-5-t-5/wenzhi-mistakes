# 问之的错题小册

家长按数学、语文、英语和单元收题；孩子一次只面对一道题。可拍照、导入扫描图或 PDF，裁题并用白框遮住旧答案，保留来源、页码、题号。

- [打开小册](https://5t5-5-t-5.github.io/wenzhi-mistakes/)
- [家长端](https://5t5-5-t-5.github.io/wenzhi-mistakes/parent.html) · [孩子端](https://5t5-5-t-5.github.io/wenzhi-mistakes/child.html)
- [先看示例](https://5t5-5-t-5.github.io/wenzhi-mistakes/parent.html?demo=1)：演示数据与正式小册分开。

孩子端可在 iPad Safari 中“分享 → 添加到主屏幕”。只打印眼前这一题，A4 留作答空间，不附答案、讲解或错题统计。打印不改变掌握状态；提交后等家长确认，做对退出轮转，题目与历史保留，可放回再练。完成后停在休息页，不自动出下一题。

## 开始使用

1. 家长端点“收一道错题”，选择科目、单元和题目来源。
2. 导入照片或 PDF，拖框裁出一题；切换白框工具遮答案。可“保存，再从本页收题”。
3. 在单元页点“让孩子练这个单元”，或由孩子选择科目。
4. 孩子端打印这一题；做完可拍作答交给家长，家长在任意已连接的家长端确认。

数学预设北师大版，英语预设沪教版（深圳用），语文预设统编版（人教社）。单元暂用通用序号，请按实际课本目录改名，不把旧版目录当成当前教材。年级、学期是小册的标注，修改不会清空或自动换一套题。

## 手机与 iPad 收题

家长端采用响应式布局，支持手机小屏、iPad 横竖屏。用 Safari 打开 `parent.html`，分享并添加到主屏幕，图标名为“家长错题本”，从桌面打开会进入家长端。建议先添加图标再录题；Safari 与桌面 Web App 可能使用不同存储。

点“收一道错题”后可直接“拍照收题”，也可从相册或文件导入图片、PDF。编辑器支持放大、缩小、移动、裁剪、遮答案，保存按钮保持可点击。照片与题目可以先在当前设备保存和打印，家庭同步可稍后配置。

## 保存与同步

**默认支持直接连接 GitHub，不需要 Cloudflare 或额外账号。** 在家长端“同步设置”中配置只授权错题私有仓库的 Fine-grained GitHub 密钥，设置家长密码，再生成加密的 iPad 配对链接。[按这里配置](GITHUB_SYNC.md)。

网页公开托管，照片、答案和记录保存在私有仓库。密钥只保存在用户自己配置的设备，不进入公开源码或备份。直连方式中的家长密码用于防止网页误操作，两端持有同一仓库权限，不能提供服务器级别的角色隔离。配对链接中的凭证用 PBKDF2 与 AES-GCM 加密；打开链接后需要输入家长密码。

未连接时仅保存于当前浏览器。电脑、Safari 和桌面 Web App 可能有独立存储，跨设备使用前必须配置同步，或导出后导入备份。连接后先写入本机与待同步队列，联网时上传；GitHub 确认后才显示“已同步”。操作编号去重、GitHub SHA 防止并发覆盖。密钥过期时需要家长更新配置。

如需严格区分家长和孩子的 API 权限，可以选用 `sync/` 中的独立接口，这是可选方案，[部署说明](sync/SETUP.md)。两种方式都使用操作队列和同一份数据格式。

任何设备清理浏览器数据前，请导出完整备份。备份包含题目、净题图、原图、答案、单元与作答历史，不含专用密钥、家长明文密码或配对钥匙。并发编辑冲突会保留本机队列，先备份再处理，不静默覆盖。

## 本地开发和验证

```sh
python3 -m http.server 8769 --bind 127.0.0.1
npm test
```

浏览器检查脚本在 `tests/`。PDF.js 5.6.205 随站点打包，来源 Mozilla，Apache-2.0 授权见 `vendor/pdfjs/LICENSE`；无需把题目传到第三方识别服务。裁题与遮答案都在设备上完成。支持现代 Safari；旧版 iPadOS 如不能导入 PDF，可先用扫描软件导出 JPG。

修改 `parent.html`、`child.html` 或模块后请更新 `sw.js` 的缓存版本，再推送；先运行 npm test，通过后推送 main，GitHub Pages 会直接发布。此项目独立于原积分卡和存折，不会修改它们的生成原稿。
